# Movie Quotes workflow

Work from the repository contract rather than memory or generic bootcamp assumptions.

## Establish scope

1. Read AGENTS.md, docs/status.md, and docs/decisions.md from the repository root.
2. Read the active slice in docs/delivery-plan.md and relevant rows in docs/requirements-traceability.md.
3. Read only the relevant product and Redberry standards sections.
4. For UI work, locate exact desktop/mobile nodes in docs/figma-inventory.md, load the Figma design-to-code skill, and fetch their context before coding.
5. Inspect the worktree and reuse established components, tokens, types, and patterns.

Ask when a required decision is open. Only make a reversible assumption when it cannot alter architecture, data ownership, security, external state, or user-visible scope.

## Deliver one vertical slice

- State outcome, exclusions, authorization, data changes, and test cases.
- Keep the slice inside the accepted PR boundary.
- Apply AGENTS.md for Laravel, React, TypeScript, Figma, localization, API, and file conventions.
- Download exact production assets; do not commit temporary Figma URLs or redraw icons.
- Do not add speculative abstractions, unrelated cleanup, or duplicate data-fetching patterns.

## Verify and close

Run focused checks while iterating and the full applicable PR gate before completion. Verify validation, authorization, failure states, and relevant desktop/mobile layouts.

Update docs/status.md, traceability statuses, and changed contracts. Report behavior, check results, Figma nodes, migrations or operations, risks, and semantic commits. The project is complete only when every required traceability row is verified and the deployed acceptance test passes.
